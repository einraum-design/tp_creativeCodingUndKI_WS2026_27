Web-Basics: HTML und CSS

Kennenlernen, Kursüberblick und die Grundlagen von HTML und CSS als Basis für alle weiteren Sketches im Browser.

Beispiele

  • HTML und CSS (diese Seite): Anwendung · Code

HTML – Hypertext Markup Language

Ein HTML-Dokument enthält die Textinhalte und Verlinkungen zu Bildern, Videos und weiteren Multimedia-Inhalten. Eine HTML-Seite besteht aus einem head- und einem body-Bereich. Die Seite wird mit „HTML-Tags“ aufgebaut und gegliedert. 

<!DOCTYPE html>
<html lang="de-DE">
    <head>
        <title>Titel der Webseite</title>

        <!-- Angabe der Zeichencodierung – damit Sonderzeichen, z. B. Umlaute, richtig dargestellt werden -->
        <meta http-equiv="Content-Type" content="text/html; charset=utf-8" />

        <!-- hier können Stylesheets, Skripte und Bibliotheken verknüpft werden … -->
    </head>
    <body>
        <!-- Inhalt der Webseite, der im Browserfenster zu sehen ist -->
    </body>
</html>

Inhalte auszeichnen

Auch die Inhalte werden mit Tags ausgezeichnet und gegliedert. Eine Überschrift wird beispielsweise von einem öffnenden und einem schließenden h1-Tag (Headline 1. Ordnung) umschlossen: 

<h1>Inhalt der Überschrift</h1>

Es gibt vorgegebene Tags für unterschiedliche Inhalte, z. B. Überschriften: <h1>, <h2>, <h3>, <h4> … oder Textabsätze: <p></p>. Mehrere Elemente lassen sich mit <div></div>-Blöcken gruppieren und strukturieren. Teile innerhalb eines Inhalts lassen sich mit Elementen markieren: 

<p>Ein Textabsatz kann beliebig lang sein. Einzelne Textteile können mit einem <span>span-Element</span> markiert werden.</p>

Bilder

Für Medieninhalte wie Bilder gibt es eigene Elemente. Mit dem img-Element wird ein Bild in die Seite eingebunden: 

<img src="Dateipfad/des/Bildes/bild.jpg" alt="Beschreibung des Bildinhalts für Lesegeräte" />

Das img-Element hat keinen Inhalt zwischen öffnendem und schließendem Tag – der Bildpfad ist ein Attribut innerhalb des Tags. Deshalb wird es nicht mit </img> geschlossen, sondern direkt im ersten Tag mit einem / beendet.

Links

Die Besonderheit der „Hypertext“ Markup Language sind die Verlinkungen zwischen unterschiedlichen Webseiten. Dafür gibt es das a-Tag. Damit kann auf andere Webseiten oder auf Stellen innerhalb einer Seite verlinkt werden. Das Attribut href legt das Ziel des Links fest, target gibt an, ob die Zielseite im gleichen oder in einem neuen Tab geöffnet wird. 

<!-- externer Link, öffnet in einem neuen Tab -->
<a href="https://p5js.org" target="_blank">Link zu einer anderen Webseite</a>

<!-- Link auf eine weitere Seite im gleichen Verzeichnis -->
<a href="seite2.html">Link zu Seite 2</a>

<!-- Link zu einer ID innerhalb der Seite -->
<!-- Damit der Link funktioniert, muss die ID irgendwo auf der Seite vergeben sein, z. B. <div id="ziel"> -->
<a href="#ziel">Link zu einer Stelle auf dieser Seite</a>

CSS – Cascading Style Sheets

Mit Stylesheets wird die Erscheinung der Webseite gesteuert: Farben, Abstände, Schriftarten, Größen usw. Styles können an unterschiedlichen Stellen geschrieben werden.

Direkt im HTML

<p style="color: #ff0000">Ein Textabsatz</p>

Im head-Bereich der Seite

<!DOCTYPE html>
<html lang="de-DE">
    <head>
        <title>Titel der Webseite</title>
        <meta http-equiv="Content-Type" content="text/html; charset=utf-8" />

        <!-- hier können Style-Regeln definiert werden: -->
        <style type="text/css">
            #content {
                background-color: rgb(224, 224, 224);
                padding: 15px;
                border: 3px solid #333333;
                margin: 30px;
            }
            h1, h2, h3, * {
                font-family: Arial, Helvetica, sans-serif;
            }
        </style>
    </head>
    <body>
        <!-- Inhalt der Webseite, der im Browserfenster zu sehen ist -->
    </body>
</html>

Als eigene .css-Datei

Eine eigenständige CSS-Datei wird im head-Bereich der Seite verknüpft. Der Vorteil: Die Datei kann für viele Seiten verwendet werden. 

<!DOCTYPE html>
<html lang="de-DE">
    <head>
        <link rel="stylesheet" href="style.css" />
    </head>
    <body>
        <!-- Inhalt der Webseite, der im Browserfenster zu sehen ist -->
    </body>
</html>

CSS-Regeln

Mit CSS lassen sich auf viele Arten Regeln für die Gestaltung der HTML-Inhalte definieren, z. B. eine Schriftart und Schriftfarbe für alle p-Elemente: 

p {
    color: rgb(20, 20, 20);
    font-family: Arial, Helvetica, sans-serif;
}

p5.js Grundlagen: Formen, Farbe, setup & draw

Beispiele

  • p5.js statisch: Anwendung · Code
  • p5.js Scheuer-Kreis: Anwendung · Code

Kommentare

Kommentare werden beim Ausführen des Programms ignoriert:

// einzeiliger Kommentar

/* Block-Kommentar
   über mehrere Zeilen,
   um etwas zu erklären
   oder um einen längeren Teil
   des Programms auszublenden */

Sketchgröße

Die Größe der Zeichenfläche wird mit der Funktion createCanvas() festgelegt. Der erste Parameter ist die Breite des Sketches, der zweite die Höhe. Alle Größen- und Positionsangaben sind Pixelmaße. 

createCanvas(800, 600);

In bestimmten Fällen wird createCanvas() mit einem dritten Parameter aufgerufen, z. B. wenn eine 3D-Szene gezeigt (WEBGL) oder ein anderer Renderer genutzt werden soll.

Shapes

Rechtecke

Die Funktion rect() kann aufgerufen werden mit

  • 4 Parametern: xPosition, yPosition, breite, höhe
  • 5 Parametern: xPosition, yPosition, breite, höhe, eckenRadius
  • 8 Parametern: xPosition, yPosition, breite, höhe, eckenRadius1, eckenRadius2, eckenRadius3, eckenRadius4

Standardmäßig wird das Rechteck von der linken oberen Ecke als Referenzpunkt aus gezeichnet. Mit rectMode() lässt sich das auf Zeichnen von der Mitte aus umstellen: 

rectMode(CENTER); // alle Rechtecke nach dem Aufruf werden von der Mitte aus gezeichnet
rectMode(CORNER); // (Standard) alle Rechtecke nach dem Aufruf werden von der linken oberen Ecke aus gezeichnet

Ellipsen

Ellipsen werden standardmäßig von der Mitte aus gezeichnet. Mit ellipseMode() lässt sich das auf Zeichnen von der linken oberen Ecke aus umstellen: 

ellipseMode(CENTER); // (Standard) alle Ellipsen nach dem Aufruf werden von der Mitte aus gezeichnet
ellipseMode(CORNER); // alle Ellipsen nach dem Aufruf werden von der linken oberen Ecke aus gezeichnet

Ein Wechsel von ellipseMode() / rectMode() wirkt sich immer nur auf die nach dem Aufruf gezeichneten Formen aus.

Bögen

Hinweis zu arc(): Start- und Endwinkel des Bogens werden nicht in Grad, sondern in Bogenmaß erwartet. Mit der Funktion radians(GRADZAHL) könnt ihr eine Gradzahl in Bogenmaß umrechnen lassen. 

// arc(xPosition, yPosition, breite, höhe, startwinkel, endwinkel, zeichentyp)
arc(300, 300, 400, 400, radians(45), radians(360 - 45), PIE);

Farben

Standardmäßig werden alle Formen mit weißer Füllfarbe und schwarzer Kontur mit 1 px Strichstärke gezeichnet.

Um eigene Farben für Formen festzulegen, gibt es die Funktionen fill() und stroke(). Standardmäßig wird das RGB-Farbsystem genutzt, und die Farbwerte werden als Zahlen im 8-Bit-Bereich erwartet: 0–255. (Zahlenbereich und Farbsystem lassen sich mit der Funktion colorMode() umstellen.)

fill() und stroke() können aufgerufen werden mit

  • 1 Parameter: Grauwert – schwarz bis weiß – 0–255
  • 3 Parametern: rotwert, grünwert, blauwert – je 0–255
  • 4 Parametern: rotwert, grünwert, blauwert, alpha – je 0–255. Alpha definiert die Transparenz.

fill() und stroke() müssen jeweils festgelegt werden, bevor eine Form gezeichnet wird. Nach einem Aufruf werden alle Formen in diesen Farben gezeichnet, bis fill() oder stroke() mit neuen Werten aufgerufen werden.

Mit noFill() und noStroke() lässt sich auch festlegen, dass keine Füllfarbe bzw. keine Kontur gezeichnet wird.

Grundstruktur: setup & draw

function setup() {

}

function draw() {

}

Die beiden Funktionen sind das Grundgerüst jedes p5.js-Sketches. Alles, was im Funktionsrumpf von function setup() – zwischen den geschweiften Klammern – steht, wird beim Programmstart einmal ausgeführt. Hier werden alle Grundeinstellungen für das Programm gesetzt und das Canvas-Element erstellt: 

createCanvas(600, 400);

Nach Ablauf von function setup() wird der Inhalt von function draw() ausgeführt. Alles, was in function draw() steht, wird immer wieder aufs Neue ausgeführt – standardmäßig 60-mal pro Sekunde. function draw() beginnt meistens mit der Funktion background(), die alles aus dem vorherigen Frame übermalt und für jeden neuen Frame eine leere Zeichenfläche bereitstellt.
